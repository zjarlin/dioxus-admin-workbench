# Markdown 展示

使用标准 Markdown 解析器生成内容，过滤原始 HTML 和危险链接，允许绑定版本化的链接及图片资源根地址。

嵌入页面可通过可选 `image_url: Callback<String, String>` 为图片选择受控传输入口；回调收到已规范化、通过协议过滤的绝对或站内地址，普通链接和引用来源的行为不变。默认直接使用原地址。回调由应用实现，不在通用组件中保存登录凭据或宿主路径。

`image_sources(source, image_base)` 返回相同规则下去重后的图片地址，包括引用式图片。应用可据此预取图片，再通过 `image_url` 映射为 Blob URL，并在文档切换和卸载时释放资源。
